§ 03 · ACORN_DB Data Layer
Shared Data Layer — ACORN_DB
The ACORN_DB object, embedded in every file, synchronizes data across apps via 7 localStorage keys.
— ACORN_DB Data Flow — Read / Write Directions —
ACORN_BOOKS
BM_BOOKS[] — Auto-saved when admin registers/edits books. Bookstore mergeAdminBooks() reads and merges into the default list. Admin → Store
adm_mr_{ch}
{status, statusLabel, note, milestones, updatedAt} — ch = paper|ebook|epub|audio|lecture|kdp. Set in Admin Multi-Revenue tab → Author Portal receives via window.storage event in real time. Admin → Author
ACORN_USER
{id, email, name, role, joinDate} — Saved on MyPage login. Checked by Bookstore header for login state and payment auth. Deleted on doLogout(). MyPage ↔ Store
ACORN_CART
[{bookId, fmt, price, qty}] — Bookstore cart. Saved via saveCart(), cleared after checkout via clearCart(). Used with acorn_pending_checkout for deferred-login checkout. Store R/W
ACORN_ORDERS
[{orderId, date, items[], total, status, userId}] — Purchase Complete 시 addOrder()로 unshift 저장. MyPage mergeOrdersFromDB()가 Purchases에 병합. Admin 대시보드 최근 주문 위젯에 표시. Store → MyPage · Admin (read)
ACORN_LIBRARY
[{bookId, format, title, purchasedAt, progress, orderId}] — 디지털 포맷(ebook·epub·audio·lecture) 구매 시에만 addToLibrary(). 중복 방지(bookId+format). MyPage My Library에 표시. Store → MyPage
ACORN_AUTHOR_SESSION
{email, name, role, loginAt} — Saved by setAuthorSession() on Author Portal login, cleared by logoutAuthor(). Planned migration to server-side JWT in Phase 1. Author R/W

Purchase → Library End-to-End Flow
Full data flow and conditional branches from Bookstore checkout to MyPage library registration.
